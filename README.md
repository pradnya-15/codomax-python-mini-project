
# Student Grade Calculator

## About
A beginner-friendly Python mini project that calculates
student marks, average, grade, and pass/fail status.

## Features
- Accepts student name and subject marks
- Calculates total and average
- Assigns grades automatically
- Displays pass or fail

## Concepts Used
- Python variables
- Lists
- Loops
- Functions
- Conditional statements
- User input and output

## How to Run
Run the file using Python 3:

python student_grade_calculator.py
